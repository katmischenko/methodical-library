Главные формулы физики

Мини-справочник для школы и базовой подготовки к ОГЭ

Механика

v = s / t

Скорость = путь / время.

a = (v − v₀) / t

Ускорение показывает, как меняется скорость.

F = ma

Второй закон Ньютона.

Fтяж = mg

Сила тяжести около поверхности Земли, g ≈ 10 Н/кг.

p = F / S

Давление = сила / площадь.

Работа, мощность, энергия

A = Fs

Если сила направлена вдоль перемещения.

N = A / t

Мощность = работа / время.

Eк = mv² / 2

Кинетическая энергия.

Eп = mgh

Потенциальная энергия тела в поле тяжести.

Тепловые явления

Q = cmΔt

Количество теплоты при нагревании или охлаждении.

Q = λm

Плавление/кристаллизация.

Q = rm

Парообразование/конденсация.

Электричество

I = q / t

Сила тока.

U = IR

Закон Ома для участка цепи.

P = UI

Электрическая мощность.

A = UIt

Работа электрического тока.

Важно: формула сама по себе не решает задачу. Сначала определи, что дано и что нужно найти, затем проверь единицы и только после этого подставляй числа.
